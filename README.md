## Selected work

### [TerraForge — Satellite Image Super-Resolution](https://github.com/Preet-Gandhi/TerraForge---Deep-Learning-for-Satellite-Image-Super-Resolution)
A deep-learning project focused on enhancing Sentinel-2 imagery while keeping spectral and geospatial consistency in view. The central challenge is improving spatial detail without presenting invented detail as reliable observation.

### [ACE — AMR Collision Avoidance & Efficiency](https://github.com/Preet-Gandhi/ACE---AMR-Collision-Avoidance-Efficiency_SIH_2026)
A multi-agent warehouse-robot simulation exploring task allocation, A* routing, time-indexed vertex and edge reservations, collision detection, deadlock recovery, and congestion-aware coordination. Includes a Streamlit dashboard and automated tests.
